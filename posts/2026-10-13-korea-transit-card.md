3. 想留纪念就额外买一张好看的实体卡（低频用或纯收藏）。

## 四、Apple Pay 的现实边界（重点）

- 韩国**只有** Apple Wallet 里的**预付型 T-money** 能在 iPhone 上刷地铁/公交，享受与实体卡相同的换乘折扣；它**不能**用于店内/线上消费。
- **实体卡无法转入 Apple Pay**：官方 FAQ 明确实体 T-money、气候同行卡、实体 K-Pass 卡都**不能**登记进 Apple Pay。
  - 唯一变通：用 Mobile T-money App 贴卡把实体卡余额**转成 T-mileage**，再给 Wallet 卡充值（**有上限**，需 App 内实测，本次未核到精确数值）。
- **开卡两条路**：
  1. Wallet App 直接开：初始充值**需「已加入 Apple Pay 的现代卡」** → 旅客基本用不了；
  2. **Mobile T-money App 开（推荐）**：无需现代卡。
- **充值**：**2026-03-18 起**支持海外 **Mastercard / Amex / UnionPay**；**Visa 不支持**；按美元结算、约 **4~5% 汇率加价**。韩国银行转账 / KakaoPay / Naver Pay（2026-09 起 iOS）无此加价。
- **实用功能**：Express Mode 快捷交通卡、**电量耗尽后 5 小时内仍可刷（Power Reserve）**、App 内可查/退余额、T-mileage 最高 1%。
- **K-Pass（政府返还 20~53%）游客不可用**：需外国人登录番号 + 本人认证。

> 一句话：**「既是实体卡、又能进 Apple Pay」的卡在韩国目前不存在。** 正确姿势是分开——**纪念卡买实体，日常刷机用 Wallet 虚拟 T-money。**

## 五、首尔成本最低：气候同行卡短期券（观光券）

首尔市官方页面（2026-10-12 有效）：

- **价格**：1日 5,000 / 2日 8,000 / 3日 10,000 / 5日 15,000 / 7日 20,000 韩元；**青少年 7 日券 13,000**。
- **形式**：**实体卡**（卡费 3,000 另计）+ 充值。Android 12+ 可开手机卡，**iPhone 只能买实体卡**。
- **覆盖**：首尔地区地铁（**含到达仁川机场 T1/T2，但不可在 T1/T2 上车**）+ 首尔市牌照市内公交/社区小巴。
  **不含**：新盆唐线、GTX、首尔以外区间地铁、广域/机场大巴、其他地区公交（范围外下车该程不能用，需到站长室补差）。
- **购卡/充值**：
  - 实体卡在**首尔交通公社 1~8 号线新型售票机**、9 号线/牛耳新设线/新林线附近便利店购买；
  - **2026-03-17 起**可用**海外信用卡**在新型售票机购买「短期券」并充值（官方博客提海外卡手续费约 **3.7%**）；
  - **2025-11-25 起**可用 Mobile T-money App 给实体卡充值；
  - 不预充值：**充值日即启用日**；1 人 1 卡，不能代买多张。
- **退款**：退款额 = 充值额 − 已使用额 − **500 韩元手续费**；须在有效期结束前申请，卡片需先在「티머니 카드&페이」注册（未注册不可退）；无韩国账户的外国人需**到 T-money 总公司领现金**。
- **附加优惠**：首尔大公园 50%、首尔植物园 50%、南山国乐堂 20~30%、난타/Painterz 等演出 30%。
- **重要变化**：30 日券（月票）**已于 2026-09-29/30 结束**，由居住者专用「기후동행패스」取代；**短期券继续运营**，且 **2026-10-01 起范围扩大到可达仁川机场**。

## 六、城际铁路：Korail Pass vs 单程票

**Korail Pass**（外国人专用）：
- 官方产品名为 **KORAIL PASS FX**，分 **2/3/4/5 日**券，各有 Adult/Child 档，适用 **177 国**（含中国）。
- 价格（多站交叉值，官方接口未公开数字）：**2 日选择权 131,000 / 3 日 186,000 / 4 日 234,000 / 5 日 275,000 韩元**。
- 「选择权（Flexible）」= 起始日起 10 天内任选 2 日（或 5 日）使用。
- **不适用**：**SRT、市内地铁、观光列车**；需用护照兑换。

**单程票参考价（KTX 一般席）**：

| 区间 | 价格 |
|---|---|
| 서울→동대구（首尔→东大邱） | 43,500 |
| 서울→신경주（首尔→新庆州/庆州） | 49,300 |
| 서울→부산（首尔→釜山） | 59,800 |
| 서울→울산 | 53,500 |
| 행신→부산 | 61,100 |

- **SRT** 同区间通常便宜 5~10%（수서→부산 SRT 约 52,600），且 **SRT 不能用 Korail Pass**。
- **判断规则**：所有 KTX 单程票之和 **≤ 131,000 → 买散票**；**≥ 131,000 → 考虑 2 日 Pass**（注意 Pass 按天不按段，一天内多段才发挥价值）。
- **济州没有铁路**，只能飞机（首尔↔济州 LCC 单程常见 4~8 万韩元）；济州市内公交可用 T-money。

## 七、发现型/纪念型卡种细节

### TTC+（T-money Travel Card Plus）
- 约 **6,000 韩元**，与 WOWPASS App 联动（换汇 + IC 刷卡支付）。
- 官方权益：N 首尔塔门票 **10% off**、爱宝乐园一日票 **30% off**、机场免税店 **6% cashback**、Olive Young/Daiso/便利店**移动商品券最高 5%**。
- 交通 + 支付 + 折扣 + 收藏一卡全占；不支持 Apple Pay。

### NAMANE（나마네카드）
- 实体预付卡，双账户（Pay 插卡支付 + 交通贴卡乘车）；每卡各 50 万上限、每人最多 4 张。
- **卡片可自定义图案（上传自己的图片）**，有 **K-POP Card / K-POP Pass** → **收藏价值最高**。
- 不支持 Apple Pay。

### WOWPASS 
- 一卡双账户（消费账户 IC 插卡 + T-money 交通账户贴卡），两账户分开充值。
- 发卡费 **5,000~6,000（不可退）**；换汇/充值/支付免手续费；ATM 取现 1,000/次；消费账户→交通账户转账 **500 韩元**。
- 回馈：GS25/CU/Dunkin/Daiso 5%、Olive Young 4%、乐天免税 15%、新罗免税 5% 等。
- **不支持 Apple Pay**；适合购物/换汇需求大的人，需靠回馈抵消发卡费。

### Discover Seoul Pass（首尔转转卡）
官方商品接口现行价（2026-10-12）：

| 产品 | 实体卡 | 手机版 | 备注 |
|---|---|---|---|
| Pick 3 Basic Pass | 49,000 | 49,000 | 从基本景点池选 3 个 |
| Pick 3 Theme Park Pass | 70,000 | 70,000 | 含主题公园池 |
| 72h Pass | 90,000 | 90,000 | ≈ USD 66 / CNY 417 |
| 120h Pass | 130,000 | 130,000 | 5 日 |

- **实体卡内置「预付式 T-money 交通卡」（发行方 ㈜한국스마트카드）+ Kona 预付消费卡**；**全国可用**、可在地铁站/便利店充值、用于地铁·公交·出租及 T-money 加盟店；**交通功能无有效期**。
- **手机版不含交通卡功能**（官方明确）；手机版含 **5 日不限量 eSIM**，实体卡也可经 App 领 eSIM。
- **AREX 机场直通列车功能临时停用**；含 Ttareungi 公共自行车。
- 退款：未使用可 30 天内全额退；一经激活（首次景点入园或交通充值）即不可退。
- **不能加入 Apple Wallet** → 定位为「实体纪念 + 备用交通卡」。

### K-Tour Pass（外国人专用）
- 2026-10-01 起**在釜山试点**，**15,000 韩元**：广域交通（铁路/长途巴士）**最高 4 折** + **1 个景点免费**，自带交通/支票卡功能。
- 你的行程（庆州/济州/大邱）**不含釜山 → 目前用不上**。

## 九、多城市行程方案示例（首尔 + 庆州/济州/大邱）

**示例条件**：首尔 + 庆州/济州/大邱等多城市（不含釜山）｜会坐 KTX/SRT｜会去首尔圈外景点（爱宝乐园/南怡岛/水原）｜购物中等（10~30 万韩元）｜Apple Pay 绑有 Mastercard / Amex / 银联 / Visa。

### 三件事分开处理

**1. 首尔市内高频日 → 气候同行卡短期券（实体，留作纪念）**
只覆盖首尔市内地铁 + 首尔市牌公交（+ 到仁川机场下车）；去爱宝乐园/南怡岛/水原等圈外行程**不能靠它**。买最贴合首尔连续停留天数的券：3 日 10,000 / 5 日 15,000 最常用。

**2. 圈外与全国通用 → Apple Wallet T-money（用 MC/Amex/银联 充值）**
- 充值只认 **Mastercard / Amex / 银联**（**Visa 不行**）→ 用 MC/Amex/银联，别用 Visa；
- 约 4~5% 汇率加价，**按需提前充一笔**，别反复小额充；
- 好处：济州岛公交、庆州/大邱市内公交地铁、爱宝乐园方向线路都能用 T-money 体系，一卡走全国。

**3. 城际铁路 → 先算单程票总和，不超 131,000 就别买 Pass**
- 示例路线「首尔→大邱→庆州→首尔」大约 10 万韩元，**买单程票更便宜**；
- 只有「首尔↔釜山往返」级别（约 119,600）才与 2 日 Pass 打平；
- 济州没有铁路，只能飞机（另计）；
- K-Tour Pass 目前只在釜山试点；本示例不含釜山，用不上。

### 购物 10~30 万韩元，要不要为回馈多买一张卡？

- **TTC+（约 6,000）**：机场免税 6% + Olive Young/Daiso/便利店最高 5%。以 20 万消费估，回馈约 1 万 > 卡费 6,000 → **值得**，且它本身是交通卡 + 支付卡 + 纪念卡。
- **WOWPASS（发卡 5,000~6,000 不可退）**：免税 15%、Olive Young 4%、便利店 5%，但**不支持 Apple Pay**、交通账户还要 500 转账费 → 只有依赖免税店折扣时才优先。
- 结论：**购物中等，TTC+ 比 WOWPASS 更划算**；日常交通仍交给 Apple Wallet T-money。
- **若行程含多个收费景点**（乐天世界/景福宫/汉江游船等）：**Discover Seoul Pass 实体卡**值得单独考虑——72h 90,000 含 70+ 景点免费/141 处折扣，卡片自带全国交通卡功能、可当纪念；但不能进 Apple Wallet。

### 最终清单（可直接照做）

| 用途 | 卡 | 花费 |
|---|---|---|
| 首尔市内连续多日 | 气候同行卡短期券 + 实体卡 | 卡 3,000 + 天数券（3 日 10,000 / 5 日 15,000） |
| 全国通用 / 圈外 / 济州 / 零散 | Apple Wallet T-money（用 MC/Amex/银联 充值） | 按次 1,550/地铁、1,500/公交 + 约 4~5% 充值加价 |
| 购物 + 纪念 | TTC+（6,000）或 NAMANE 自定义图案卡 | 6,000 左右 |
| 若玩多个收费景点 | Discover Seoul Pass **实体卡**（自带全国交通卡，当纪念） | 72h 90,000 / 120h 130,000 |
| 城际 | 单程 KTX 票（先算总价，不超 131,000 不买 Pass） | 见第六节 |
| 机场往返 | AREX 普通列车 | 4,750 / 5,350 |

- **可达**：首尔市官方（气候卡/运价）、T-money 官方博客（blog.tmoney.co.kr）、WOWPASS 官网、NAMANE 官网、Discover Seoul Pass 官方接口、Korail 官方接口、web.archive.org。
- **本工作区不可达**：`www.t-money.co.kr` / `pay.tmoney.co.kr`（站点侧对境外/机房 IP 限制，经出口节点亦被拒）、`korail.com` 公开页（SPA，非浏览器/境外返回兜底页）。相关结论均以可达的官方博客 + 官方接口为准，价格类数字标注了「多站交叉」。
- **Korail Pass 具体价格**：官方公开接口未含数字（在预订流程内呈现），故仍为多站交叉参考值，其余分档/命名已由官方接口确认。
- 本方案未对工作区的 IPv6 分流规则做任何改动；所有出口取数均为一次性只读。
